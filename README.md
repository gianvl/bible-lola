# Bible (for Lola)

A simple, ad-free Android Bible made for my grandmother. It does one thing: lets you read the Bible comfortably.

- Old and New Testament, all 66 books
- **English (King James Version)** or **Tagalog (Ang Dating Biblia, 1905)**, switched with one toggle; the menus follow the chosen language
- Large, adjustable text (A− / A+), remembered between visits
- Opens straight to the chapter you were last reading
- **Read aloud** with the phone's built-in voice
- Follows the phone's dark mode
- Works completely offline: no internet permission, no ads, no tracking ([privacy policy](PRIVACY.md))

## Bible text sources

Both texts are in the public domain and bundled in `app/src/main/assets/bible/`.

| Translation | Source |
|---|---|
| King James Version (1769 standard text) | [eBible.org `eng-kjv2006`](https://ebible.org/Scriptures/details.php?id=eng-kjv2006) |
| Ang Dating Biblia (Philippine Bible Society, 1905) | [CrossWire SWORD module `TagAngBiblia`](https://crosswire.org/sword/modules/ModInfo.jsp?modName=TagAngBiblia) |

The assets are generated by `tools/build_bible_assets.py`, which also checks that every chapter and verse is present:

```sh
curl -LO https://ebible.org/Scriptures/eng-kjv2006_vpl.zip && unzip eng-kjv2006_vpl.zip -d kjv
curl -LO https://crosswire.org/ftpmirror/pub/sword/packages/rawzip/TagAngBiblia.zip && unzip TagAngBiblia.zip -d adb
python3 -I tools/build_bible_assets.py kjv/eng-kjv2006_vpl.txt adb/modules/texts/ztext/tagangbiblia app/src/main/assets/bible
```

## Tech

Kotlin, Jetpack Compose (Material 3), Navigation Compose, DataStore, kotlinx.serialization, Android TextToSpeech.
Single activity; manual dependency injection via `AppContainer`. minSdk 26, targetSdk 36.

```
app/src/main/java/com/lolabible/app/
├── data/      Books catalog, ChapterRef, BibleRepository (assets), SettingsRepository (DataStore)
├── speech/    Speaker (TextToSpeech wrapper)
└── ui/        NavHost, Home, Chapters and Reader screens, theme
```

## Building

Requirements: JDK 17+ and the Android SDK (Android Studio includes both).

```sh
./gradlew testDebugUnitTest   # unit tests (also validate the bundled Bible text)
./gradlew assembleDebug       # debug APK: app/build/outputs/apk/debug/
./gradlew lintDebug
```

### Release signing

Create an upload key once and keep it **safe and out of git** (losing it means asking Google to reset it):

```sh
keytool -genkeypair -v -keystore upload-key.jks -alias upload -keyalg RSA -keysize 4096 -validity 10000
```

Then create `keystore.properties` in the project root (it is git-ignored):

```properties
storeFile=upload-key.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

```sh
./gradlew bundleRelease       # signed bundle: app/build/outputs/bundle/release/app-release.aab
```

## Publishing to Google Play

1. Create a [Play Console](https://play.google.com/console) developer account (one-time US$25 fee, identity verification).
2. Create the app, then fill in **App content**: privacy policy URL (link to `PRIVACY.md` on GitHub), ads = _No_, Data safety = _No data collected or shared_, content rating questionnaire, target audience.
3. Upload `app-release.aab` and opt in to Play App Signing.
4. New **personal** developer accounts must run a **closed test with at least 12 testers for 14 days** before production access is granted. Family members make good testers.
5. Add a store listing: short description, 512×512 icon, feature graphic (1024×500), and at least 2 phone screenshots.
6. Bump `versionCode` in `app/build.gradle.kts` for every upload.
